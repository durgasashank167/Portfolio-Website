# Personal Portfolio Website

A responsive, single-page portfolio starter built with HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open the `portfolio_website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Personalize before publishing
Search `index.html` for these sample values and replace them:
- `Your Name`
- `your.email@example.com`
- LinkedIn and GitHub profile URLs
- `Add GitHub link` project links
- CGPA, academic details, internship dates, and skills if anything has changed

This starter is a static website. It does not currently include a backend, login system, or database.
